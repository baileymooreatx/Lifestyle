# FDA Daily Values

The FDA's Daily Values (DVs) for a 2,000-calorie diet which are the reference 
amounts used to calculate the %DV on U.S. Nutrition Facts labels

| Nutrient           | Daily Value |
|--------------------|-------------|
| Total Fat          | 78 g        |
| Saturated Fat      | 20 g        |
| Cholesterol        | 300 mg      |
| Sodium             | 2,300 mg    |
| Total Carbohydrate | 275 g       |
| Dietary Fiber      | 28 g        |
| Added Sugars       | 50 g        |
| Protein            | 50 g        |
| Vitamin D          | 20 mcg      |
| Calcium            | 1,300 mg    |
| Iron               | 18 mg       |
| Potassium          | 4,700 mg    |

Notes:

- These are the **current FDA values** (updated with the 2016 label revision).
  Older labels cited different figures (e.g., 65 g total fat, 300 g
  carbohydrate, 2,400 mg sodium, 25 g fiber, 1,000 mg calcium), so you may still
  see those on pre-2020 packaging.
- The %DV for a serving is simply (amount in serving ÷ the DV above) × 100, so
  100% DV equals one day's reference amount.
- These reference values apply to adults and children age 4+; they are general
  guidelines, not individual prescriptions, and actual needs vary with age, sex,
  and activity level.
